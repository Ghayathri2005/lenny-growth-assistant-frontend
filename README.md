# 🚀 Lenny Growth Assistant Frontend

A modern, responsive AI-powered frontend application built with **React**, **TypeScript**, and **Vite**. This project provides an intuitive user interface for interacting with the Lenny Growth Assistant platform, enabling users to engage with AI-driven features through a clean and user-friendly experience.

---

## 📌 Overview

The Lenny Growth Assistant Frontend is designed to provide a fast, scalable, and responsive user experience. It communicates with backend APIs to deliver AI-powered interactions while maintaining an elegant and accessible interface.

---

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/lenny-growth-assistant-frontend.git
```

Go into the project

```bash
cd lenny-growth-assistant-frontend
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

# ⚙️ Environment Variables

Create a `.env` file using the provided `.env.example`.

Example:

```env
VITE_API_URL=http://localhost:5000
```
